# Adobe PDF

A privacy-first, open-source native Android PDF workspace built from scratch.

## Implemented in the first development batch
- Kotlin + Jetpack Compose Android application shell
- Android Storage Access Framework file selection and export
- Local PDF merge, first-page extraction, page rotation and text overlay
- PDF page-count inspection
- No account, cloud upload, watermark, or server dependency for these operations

## Build
Use Android Studio with JDK 17 and Android SDK 35. Open the repository and run the `:app` configuration.

## Roadmap
Full document viewer and thumbnails, page reorder/delete/range extraction, annotations, image insertion, OCR, conversion, compression, forms, password protection, redaction and digital signatures.

## Inspiration and licensing
Stirling PDF, BentoPDF and Sejda are feature references, not bundled source code or assets. This project is independently implemented. Review third-party library licences and attribution requirements before redistribution.
